# Task 2 — Exploratory Data Analysis (EDA)

This project analyzes `books_dataset.csv` generated by Task 1.

## Questions
1. What are the dataset dimensions and data types?
2. Which columns have missing values?
3. What are the minimum, maximum, average, and median prices?
4. How are ratings distributed?
5. Do average prices vary by category?
6. Are there duplicate records, invalid values, or outlier candidates?

## Run
1. Copy `books_dataset.csv` from Task 1 into this folder.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python eda_analysis.py`

## Outputs
- `eda_summary.txt`: dataset structure, statistics, missing values, quality checks and hypothesis checks.
- `books_cleaned.csv`: duplicate rows and duplicate product URLs removed.
- `price_distribution.png`: histogram of book prices.
- `rating_counts.png`: bar chart of ratings.
- `category_average_price.png`: category average prices when category data is available.

## Hypotheses
- H1: Book prices should be non-negative.
- H2: Ratings should be between 1 and 5.
- H3: Product URLs should uniquely identify books.
- H4: Average prices may differ by category (descriptive comparison only).

The analysis calculates results from the actual CSV; it does not invent statistics. IQR outliers are flagged for review, not automatically deleted. Check website terms and scrape responsibly.
